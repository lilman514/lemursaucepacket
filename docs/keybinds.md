# Keybinds

These are the keys you start with. Most are each mod's own default; the pack moves a few so that the ones you use most don't clash. Change any of them in Settings → Controls → Key Binds. Its search box finds an action or a key.

## Sorting

**Sorting** (Inventory Profiles Next) works in your inventory and in every chest, barrel and shulker box:

- The buttons at the top right of each half sort it (plain, in columns, in rows).
- **Move All** (the arrow) takes everything out of the container, or puts your inventory into it. Your hotbar stays put. Hover the arrow to see the keys that include the hotbar or move only the kinds of items the other side already has.
- Auto Refill tops up a hotbar stack that runs out and swaps a tool for a spare before it breaks.

## The ESC menu and the HUD layout

The ESC menu's buttons press some of these keys for you, so the menu works even if you rebind them. The list above marks which ones.

**Edit HUD layout** (Controls > LemurSaucePacket) has no key by default. The ESC menu's HUD Layout button and `/hudlayout` open the same screen.
